# Sneaky AI

Early AI signals for people building AI in India. Five items at most, every morning at 06:00 IST.

**Get the Android app:** open this link on your phone, then tap Install:
https://github.com/saiganeshcurious/sneaky-ai-feed/releases/latest/download/SneakyAI.apk

This repository holds the app's daily data (`feed.json`), updated automatically every morning.
No sponsors. No affiliate links. Ever.
